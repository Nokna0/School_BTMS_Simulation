# School_BTMS_Simulation

> 3학년 1학기 「고급물리학」 수행평가 — 열기관의 열역학 시뮬레이션

웹 브라우저에서 바로 실행되는 **단일 HTML 파일** 열기관 시뮬레이터 모음입니다.
2015 개정 교육과정 고급물리학 **열역학 단원**의 개념(열량·비열, 열역학 제1법칙,
열기관, 카르노 효율·제2법칙)을 시각적으로 확인할 수 있도록 만들었습니다.

## 조작법 (붕괴 시뮬레이터)

| 컨트롤 | 기능 |
|---|---|
| ▶ START / ⏸ STOP | 시뮬레이션 시작·정지 |
| ↺ | 초기 상태로 리셋 |
| 1× / 2× / 4× | 시뮬레이션 배속 |
| 엔진 부하 (10–100%) | 연소 발열 Q_in 조절 |
| 냉각 시스템 가동률 (0–100%) | 라디에이터 방열 Q_out 조절 |

**관전 포인트:** 냉각 가동률을 낮추면 `Q_in > Q_out` 이 되어 온도가 발산하고,
107 → 130 → 150 → 200 °C 임계온도에서 고장이 연쇄적으로 발생합니다.

## 조작법 (급속 충전 시나리오 — 2-4-4-1)

급속 충전 중 배터리 셀의 발열을 **BTMS 적용 / 냉각 없음** 두 경우로 비교합니다.

| 입력값 | 범위 | 의미 |
|---|---|---|
| 충전 전류 | 50–350 A | 줄 발열 `Q_gen = I²·R` 의 크기 |
| 외부 온도 | −10–45 °C | 저열원·주위 온도 (초기 셀 온도와 동일) |
| 충전 시간 | 5–60 분 | 시뮬레이션 구간 길이 |
| 배터리 용량 | 20–100 kWh | 열용량 `m·c` 와 팩 내부저항 `R` 을 결정 |

| 출력값 | 의미 |
|---|---|
| 최고 온도 | 충전 구간 중 도달한 셀 최고 온도 |
| 평균 온도 | 충전 구간 셀 온도의 시간 평균 |
| 냉각 효율 | 누적 제거열 / 누적 발생열 `η_cool = Q_제거 / Q_발생` |
| 에너지 손실 | 줄열로 버려진 누적 에너지(kJ)와 공급 전력 대비 비율 |

**관전 포인트:** 기본 입력값(280 A · 60 kWh · 25 °C)에서 냉각 없는 배터리는
약 25분(SOC 85%)에 셀 온도가 **80 °C 열폭주**에 도달해 충전이 차단되고,
BTMS 배터리는 약 42 °C 부근에서 평형을 유지하며 충전을 완료합니다.
셀 온도가 45 °C(경고)를 넘으면 발열반응으로 내부저항이 급증하는
**열폭주 양성 피드백**이 작동해, 냉각이 없는 배터리의 온도 곡선이
급격히 꺾여 올라가는 것을 볼 수 있습니다(전류↑·용량↓ 일수록 더 빨리 발생).

## 물리 모델 요약

핵심 관계식은 교육과정 공식을 그대로 사용합니다 (자세한 내용은
[`THERMODYNAMICS.md`](THERMODYNAMICS.md) 참고).

```
열량 보존(제1법칙, W≈0):  m·c·(dT/dt) = Q_in − Q_out      (m·c = 36 kJ/K)
카르노 효율(제2법칙):      η = 1 − T_C / T_H               (절대온도 K)
자연 방열(열의 이동):       Q_passive ∝ (T − T_주위)
줄 발열(전기 → 열):        Q_gen = I²·R                    (급속 충전 시나리오)
```

| 교육과정 개념 | 구현 |
|---|---|
| 절대온도(켈빈) | `T[K] = T + 273.15` |
| 열량·비열·열용량 | `Q = m·c·ΔT` |
| 열역학 제1법칙 | `ΔU = Q_in − Q_out` |
| 열기관(고·저열원) | Q_in 흡수 / Q_out 방출 |
| 카르노 효율·제2법칙 | `η = 1 − T_C/T_H` |
| 전기에너지 → 열(줄열) | `Q_gen = I²·R·t` (급속 충전) |

## 표시 / UX

- **라이트 모드 기본**, 브라우저·OS가 다크 모드면 자동으로 다크 테마
  (`prefers-color-scheme`)
- 비교 시뮬레이터·급속 충전 시뮬레이터는 **🌙/☀ 테마 토글**을 제공하며
  선택은 `localStorage` 에 저장되고, 첫 페인트 전에 테마를 결정해
  화면 깜빡임(FOUC)을 방지
- 급속 충전 시뮬레이터는 **키보드 단축키** 지원 (`Space` 시작/정지, `R` 초기화)
  및 입력 슬라이더에 `aria-label` 부여
- 배속 조절(1× ~ 8×), 초기화, 진행률·충전률 표시
- 급속 충전 시뮬레이터의 배터리 애니메이션은 `requestAnimationFrame`
  렌더 루프로 **배속과 무관하게 부드럽게** 동작하며, 열폭주 시
  맥동 글로우·연기·불씨 효과를 표시
- 그래프 배경은 카드 배경색과 일치하도록 처리
- HiDPI(레티나) 디스플레이 대응 · 좁은 화면 반응형 레이아웃

## 물리 모델 일관성

- **세 시뮬레이터 모두** 온도 변화를 **열역학 제1법칙(W≈0) 기반 열수지**
  `m·c·(dT/dt) = Q_gen − Q_loss` 형태로 적분합니다(명시적 오일러법).
- 열기관 두 시뮬레이터는 열효율을 교육과정의 **카르노 효율
  `η = 1 − T_C/T_H`** (절대온도)로 구현합니다.
- 급속 충전 시뮬레이터는 발열원으로 **줄열 `Q_gen = I²·R`** 을 사용하고,
  BTMS 냉각·자연 방열은 동일한 **뉴턴 냉각 `Q ∝ (T − T_외부)`** 형태를 따릅니다.
- "냉각 없는" 쪽의 가열 폭주는 세 파일 모두 동일한 발상(고온 → 열전달 저하
  또는 내부저항 증가 → 양성 피드백)으로, 1·2법칙을 위반하지 않는 시나리오
  보정 요소입니다.
- 디자인 토큰·테마(라이트 기본)·폰트(돋움)·카드 레이아웃을 세 파일이 공유합니다.
